   Cost = 864 x 0.10 = 86.40 dollars.

   50,000 / 5 = 10,000 units per month.
3. "Percentage points" applies to quantities already in percent.
   40 and 30 dollars are prices, not percents. Percent change =
   (30 - 40) / 40 = -25 percent.
4. Effective rate = 10^15 x 0.40 = 4 x 10^14 FLOP/s. Time =
   10^18 / (4 x 10^14) = 2,500 seconds.
5. 90,000 / 3 = 30,000 dollars per year.
6. Price per token = 4 / 1,000,000 dollars. Cost = 2,000 x 4 /
   1,000,000 = 0.008 dollars (0.8 cents).
7. PV = 100,000 / 1.10 + 100,000 / 1.10^2 = 90,909.09 +
   82,644.63 = 173,553.72 dollars.
8. Set 100 - 2P = 20 + 3P. Then 80 = 5P, P = 16 dollars.
   Q = 100 - 32 = 68 units.
9. The latency constraint binds. Throughput is irrelevant once the
   2-second latency cap is violated at 3 seconds.

    volume never covers any fixed cost or risk, growth multiplies
    exposure without profit.
